## 🚀 Featured Project

### [Smart Clinic Management System](https://github.com/AhmedELSayed138/Smart-Clinic-Management-System)

> A full-stack, role-based clinic appointment booking system built from scratch.

**What it does:**
- Patients register, browse doctors, and book appointments
- Doctors manage their own schedules
- Admins control the entire clinic system

**What's under the hood:**

| Layer | Tech |
|---|---|
| Frontend | React · React Router · Tailwind CSS |
| Backend | Node.js · Express.js · REST APIs |
| Database | PostgreSQL · Relational Schema Design |
| Security | JWT Authentication · Bcrypt · SQL Injection Prevention |
| Testing | Postman · Manual Integration Testing |

> Built with an MVC architecture, parameterized SQL queries, global error handling, and role-based access control across 3 user types.
