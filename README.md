### 🏥 Smart Clinic Management System

**Full-Stack Web Application**

```text
BACKEND      → Node.js + Express.js
DATABASE     → PostgreSQL
FRONTEND     → React.js
ARCHITECTURE → MVC
AUTH         → JWT
SECURITY     → bcrypt
API          → REST
TESTING      → Postman
ROLES        → Patient / Doctor / Admin
```

A secure clinic management system designed around three user roles: **Patient, Doctor, and Admin**.

**Key features:**

* JWT authentication
* Role-based access
* Password hashing with bcrypt
* PostgreSQL relational database
* RESTful APIs
* Global error handling
* SQL injection prevention
